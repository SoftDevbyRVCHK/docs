# Roadmap

Детальные задачи по участникам ведутся на Kanban-доске GitHub Projects.

### Сейчас
Запуск базового прототипа и связка клиента с C++ сервером:
- Обмен JSON-пакетами по WebSockets.
- Игровая зона: отрисовка космоса, планет на эллиптических орбитах и корабля игрока.
- Базовая физика движения корабля и гравитации планет.
- Первичный дизайн основных экранов и базовая документация (`README.md`, `ERD.md`, `CONTRACTS.md`, `ROADMAP.md`).

### Потом
Основные игровые механики (точный объём будет добавлен после завершения базового прототипа):
- Подключение базы данных к серверу.
- Экран ангара: конструирование корабля по сетке 32x32 и серверная валидация сборки.
- Взаимодействие с планетами в игровой зоне (магазин / торговля, базовые квесты, окно коммуникатора).
- Базовая боевая механика (стрельба, пробитие модулей, расход ресурсов).
- Завершение макетов интерфейса.

### В будущем
Дополнительные механики:
- Глобальная карта со звёздными системами, разделением на территории государств и быстрым перемещением.
- Система фракций, репутации и случайных событий.
- Набор экипажа, прокачка характеристик и бортовой дневник.
