# Контракты взаимодействия Клиент-Сервер (SpaceOdyssey)

Обмен данными между клиентом и C++ сервером происходит в формате JSON.

## Базовая структура сообщений

Все пакеты используют общие ключи верхнего уровня:
* `type` — тип запроса или ответа
* `id_client` — идентификатор клиента (передается после входа на сервер)
* `data` — основные данные сообщения
